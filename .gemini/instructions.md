# 프로젝트 규칙 (Kotlin & Jetpack Compose)
## 0. 필수규칙
- 반드시 한국어로 작성해줘
- 설명은 친절하고 자세하게
- 변경될 코드도 같이 적어줘
## 1. 아키텍처
- 우리 프로젝트는 **MVVM 패턴**을 엄격하게 지켜야 해.
- Business Logic은 반드시 ViewModel에서 관리하고, UI(Compose)는 상태만 관찰하도록 리뷰해줘.
- 기능이 겹치는 함수가 있을 시에는 util에 함수를 만들어서 쓸 수 있도록 유도 해줘.

## 2. 코드 스타일
- 모든 UI는 **Jetpack Compose**로 작성해.
- 함수 이름은 PascalCase를 사용하고, Modifier는 항상 첫 번째 파라미터로 받도록 체크해줘.

## 3. 기타
- API KEY, 서버 주소같이 민감한 정보는 절대 절대 들어가서는 안돼
- 성능상 문제가 될 수 있는 `recomposition`이 과하게 일어날 것 같은 부분은 지적해줘.
- 설명은 친절하고 자세하게, 한국어로 해줘!
